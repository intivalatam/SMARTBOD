SMARTBOD en tu teléfono

Se instala desde el navegador como aplicación web. Usa la misma cuenta y los mismos datos.

  1. iPhone: abre esta dirección en Safari, pulsa Compartir y elige Añadir a pantalla de inicio. Activa Abrir como app web si aparece.
  2. Android: abre el menú del navegador y busca Instalar aplicación o Añadir a pantalla de inicio.
  3. Huawei: abre el menú de tu navegador y busca Añadir a pantalla de inicio. Según el sistema y navegador puede instalar una app web o crear un acceso directo; si no aparece, puedes seguir usando la web.

➕ Nuevo Producto Personalizado

¿Cómo se utiliza este producto?

Registra el stock en envases o bolsas. Si una bolsa rinde 40 porciones, cada plato vendido usa 1/40 de bolsa. En cada receta eliges la dosis y si se descuenta al preparar o al servir. La venta directa del envase sigue descontando una unidad completa.

Se optimiza la foto y se guarda en la nube al guardar el producto. Máximo 10 MB de entrada.

Ingredientes por receta completa

1 envase para una receta de 24 porciones es válido. Si el envase alcanza para 48, elige «Un envase rinde X porciones» e indica 48: al preparar 24 se usará medio envase. También puedes ingresar cantidades como 0.25.

¿Es suficiente para la preparación?

Este botón guarda los cambios de receta y registra la preparación en una sola operación. La venta descuenta las porciones listas y los insumos configurados para descontarse al vender.
